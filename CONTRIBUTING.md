# Contributing

Thank you for your interest in contributing to Dual Camera Stop Motion Studio.

## Getting Started

1. Fork the repository
2. Clone your fork

```bash
git clone https://github.com/kundanbhosale/dual-camera-stop-motion-studio.git
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

## Development Guidelines

* Use TypeScript
* Follow existing code style and conventions
* Keep components focused and reusable
* Prefer hooks for shared logic
* Test changes before submitting

## Submitting Changes

1. Create a feature branch

```bash
git checkout -b feature/my-feature
```

2. Commit your changes

```bash
git commit -m "Add feature"
```

3. Push your branch

```bash
git push origin feature/my-feature
```

4. Open a Pull Request

## Reporting Bugs

When reporting issues, please include:

* Browser and version
* Operating system
* Camera hardware used
* Steps to reproduce
* Expected behavior
* Actual behavior

## Feature Requests

Feature requests are welcome. Open an issue describing:

* The problem you're trying to solve
* Proposed solution
* Alternative approaches considered
