# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful and harassment-free experience for everyone.

## Expected Behavior

* Be respectful and professional
* Welcome constructive feedback
* Focus on collaboration
* Respect differing viewpoints
* Assume positive intent

## Unacceptable Behavior

* Harassment or discrimination
* Personal attacks
* Trolling or insulting comments
* Publishing private information
* Any conduct that creates an unwelcoming environment

## Enforcement

Project maintainers may remove comments, commits, issues, or contributions that violate this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces, including:

* GitHub Issues
* Pull Requests
* Discussions
* Project communication channels

By participating, you agree to follow these guidelines.
